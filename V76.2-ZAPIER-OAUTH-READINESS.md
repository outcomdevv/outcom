# V76.2 — Zapier OAuth readiness (no credentials required)

Changed: lib/zapier.ts (new), lib/oauth.ts, lib/db/index.ts, app/api/oauth/[provider]/{start,callback}/route.ts,
app/api/integrations/discover/route.ts, app/connect/connect-client.tsx, scripts/v72-check.mjs, package.json (test:unit), tests/*.

- Discovery extracted into lib/zapier.ts: follows links.next (same-origin only), dedupes, partial results on mid-listing failure, 429 Retry-After, typed errors.
- Default Zapier scopes: `profile zap:account:all` (read-only, includes shared Zaps; request sent with include_shared=true). Override with ZAPIER_OAUTH_SCOPES.
- Page size 10 (documented default); previously limit=100 which the docs do not support.
- OAuth state consumed atomically (DELETE ... RETURNING); provider guard uses hasOwn; callback redirects with specific error codes.
- Token refresh: invalid_grant => OAuthReauthRequired (UI shows Reconnect); no refresh-on-every-call when expiry unknown; 401 from Zapier triggers one forced refresh + retry.
- Run `npm run test:unit`.
