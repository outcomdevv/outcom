# V67 — Protection onboarding flow

The protection flow now keeps the user inside one linear setup:

1. Name the automation.
2. Select one or more outcomes.
3. Configure the exact business requirement for each selected outcome.
4. Create protection.
5. Jump directly to the generated webhook endpoint.

The automation is not created or modified by these fields. The fields configure what Outcom verifies after the automation runs.

For manual Zapier webhook mode, the only provider-side manual action remains adding the final Webhooks by Zapier POST step.
