# V75.2.1 — Google Sheets OAuth Type Fix

Fixes the production TypeScript failure where Google Sheets routes called `getValidAccessToken("google_sheets")` but `OAuthProvider` only allowed `ghl | zapier | make`.

Changes:
- Adds `google_sheets` to `OAuthProvider`.
- Adds Google OAuth authorization/token configuration.
- Requests offline access so a refresh token can be returned.
- Adds Google userinfo profile handling for OAuth callback persistence.
- Keeps Google Sheets read-only scopes for the current verification flow.
