# V76.1 — Google OAuth Regression Fix

V76 reintroduced an older `lib/oauth.ts` that omitted the existing `google_sheets` OAuth provider. This caused TypeScript errors in the already-existing Google Sheets routes and adapter:

- `app/api/google-sheets/files/route.ts`
- `app/api/google-sheets/sheets/route.ts`
- `lib/adapters/google-sheets.ts`

V76.1 restores the V75.2.1 OAuth provider definition and Google OAuth handling while keeping the V76 Evidence Graph changes.

This is a regression fix only. It does not change the Evidence Graph behavior.
